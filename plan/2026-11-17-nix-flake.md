# Plan: Install and configure omateams from this fork's own flake

## Approved decisions (from the spec)

- **New files:** `flake.nix` (plus `flake.lock`), `nix/package.nix`,
  `nix/qt-version.nix`, `nix/home.nix`, `nix/nixos.nix` and
  `nix/checks.nix`. The shape follows `nixarchy-omapod`.
- **No change to app code.** The `BarWidget.qml` colour fix stays a
  build-time substitution. `install.sh` is untouched.
- **Inputs:**
  - `nixpkgs`: `github:NixOS/nixpkgs/nixos-unstable`.
  - `nixpkgs-qt`: `github:NixOS/nixpkgs/614ba4ae06fe11e36b386321b8735d1a6bf441db`,
    a `master` revision. Its `qt6.qtwebengine` is `6.140.0`, and that,
    `qtbase-6.12.0` and `qtdeclarative-6.12.0` were all checked present in
    cache.nixos.org.
  - `home-manager`, with `inputs.nixpkgs.follows = "nixpkgs"`, used only by
    the checks.
- **The package is built entirely with `nixpkgs-qt`'s `callPackage`**: one
  stdenv, one glibc, one Qt set. Only `hyprland` comes from the consumer.
- **The Qt assert fails the build** unless QtWebEngine is `6.140.0` final or
  newer. `compareVersions` ranks `6.140.0-rc` above `6.140.0`, so the
  predicate compares the part before `-`. A pre-release of a later version
  is accepted.
- **The version is read from `manifest.json`** and passed to qmake.
- **Everything else is carried over from the current package**:
  - the `Service.qml` substitutions with `--replace-fail`;
  - the `BarWidget.qml` substitution;
  - the install layout (binary, desktop entry, icon, plugin without
    `install.sh`);
  - `qtWrapperArgs`, which puts Hyprland, libnotify, coreutils and bash on
    `PATH`;
  - the `systemd-run` wrapper (`MemoryHigh=12G`, `MemoryMax=16G`,
    `MemorySwapMax=0`) with its unscoped fallback when there is no user bus;
  - the install checks.
- **No `settings` option.** The shell never reads manifest defaults, so
  settings stay with the shell UI.
- **Home-manager module `programs.omateams`:**
  - `enable`;
  - `package`, which defaults to the flake package;
  - `home.packages`;
  - `programs.nixarchy.plugins.omateams.src`, set only when that option is
    declared. The test is on `options`, never `config`.
- **NixOS module `programs.omateams`:** `enable`; `package`, which defaults to
  the flake package with `config.programs.hyprland.package`; and
  `environment.systemPackages`.
- **Order:** this lands after PR #1 merges. Rebase `feat/nix-flake` onto
  `master` before opening its PR.
- **Not in this plan:** the consumer change in the owner's NixOS config. It
  is its own task in that repo, under that repo's workflow, after this
  merges. The spec's "Consumer change" section is the brief for it.

## Repo traps (apply to every step)

- **Source paths.** `nix/package.nix` sits under `nix/`, so its fileset root
  is `../.`.
- **Git and flakes.** A flake only sees files tracked by git, so new files
  must be `git add`ed before `nix build` or `nix flake check` will see them.
  Implementers edit files only; the lead runs the git add and the builds.
- **Builds stay on this host.** `nix build` and `nix flake check` run here,
  and never on p510.
- **Line numbers** refer to `~/.config/nixos-omateams-cap/pkgs/omateams/default.nix`
  as it is now. Read that file in full before step 1.
- **Style.** Nix in the omapod style: `lib.` qualified names, short
  why-comments, no `with`.

## Steps

1. **`nix/package.nix` and `nix/qt-version.nix`: the package.**
   - **`nix/qt-version.nix`** holds the predicate:

     ```nix
     lib: v:
     let base = lib.head (lib.splitString "-" v); in
     lib.versionOlder "6.140.0" base || v == "6.140.0"
     ```

   - **`nix/package.nix` arguments** are the same as
     `pkgs/omateams/default.nix:1-11`.
   - **Copy over:**
     - the derivation from `default.nix:17-104`;
     - the version assert, placed after the argument set's colon and before
       `stdenv.mkDerivation`:
       `assert (import ./qt-version.nix lib) qt6.qtwebengine.version;`.
   - **Changes from the copy:**
     - `version = (lib.importJSON ../manifest.json).version;`
     - `src = lib.fileset.toSource { root = ../.; fileset = lib.fileset.unions [ ../host ../ui ../assets ../manifest.json ../preview.png ../LICENSE ]; };`
       This replaces `fetchFromGitHub`.
     - `meta.homepage = "https://github.com/olafkfreund/omateams";`
     - The install checks also grep the wrapper for `MemoryHigh=12G` and
       `MemorySwapMax=0`.
     - **Version check against the built binary.** The manifest grep alone
       proves nothing now, because the version comes from the manifest. So
       the install check also looks for the version in the built binary,
       `$out/bin/.omateams-wrapped`, which is the ELF the Qt wrapper `exec`s.
       `QStringLiteral` stores the string as UTF-16, so a plain grep finds
       nothing (checked on the installed 1.4.1). The check is:
       `${python3}/bin/python3 -c "import sys; sys.exit('${version}'.encode('utf-16-le') not in open(sys.argv[1],'rb').read())" $out/bin/.omateams-wrapped`.
       Add `python3` to the arguments, used only in `installCheckPhase`.
   - **Keep the rest exactly:** `postPatch`, `installPhase`, `postInstall`,
     `qtWrapperArgs`, `postFixup` and the remaining install checks.

   Verify (lead): after `git add`, run

   ```bash
   nix build --impure --expr 'let f = builtins.getFlake (toString ./.); in f.packages.x86_64-linux.default'
   ```

   once step 2 exists, or the step 2 command. Expect a build that passes its
   install checks.

2. **`flake.nix` and `nix/checks.nix`: outputs and checks.**
   - **Inputs** as above.
   - **Let bindings:**
     - `systems = [ "x86_64-linux" "aarch64-linux" ]`;
     - `forAll` as in omapod;
     - `pkgsQt = s: nixpkgs-qt.legacyPackages.${s}`.
   - **Outputs:**
     - `packages.${s}.omateams = (pkgsQt s).callPackage ./nix/package.nix { }`,
       with `default` pointing at it.
     - `apps.${s}.default`: runs it.
     - `overlays.default = final: _: { omateams = (pkgsQt final.stdenv.hostPlatform.system).callPackage ./nix/package.nix { hyprland = final.hyprland; }; }`.
     - `homeManagerModules.default = import ./nix/home.nix self;`
     - `nixosModules.default = import ./nix/nixos.nix self;`
     - `checks.${s} = import ./nix/checks.nix { inherit self nixpkgs home-manager; pkgs = nixpkgs.legacyPackages.${s}; system = s; };`
   - **`nix/checks.nix` returns:**
     - **`package`**: the package.
     - **`qt-version`**: a `runCommand` that fails at evaluation unless the
       predicate rejects `6.139.0` and `6.140.0-rc` and accepts `6.140.0`,
       `6.140.1` and `6.141.0-rc`.
     - **`hm-nixarchy`**: a home-manager evaluation (with
       `home-manager.lib.homeManagerConfiguration`, and `home.stateVersion`,
       `home.username` and `home.homeDirectory` set) with the module enabled.
       It also includes a stub module that declares
       `options.programs.nixarchy.plugins = lib.mkOption { type = lib.types.attrsOf (lib.types.submodule { options.src = lib.mkOption { type = lib.types.str; }; }); default = { }; };`.
       It asserts that `config.programs.nixarchy.plugins.omateams.src` ends in
       `/share/omateams/plugin`.
     - **`hm-plain`**: the same without the stub. It asserts that
       `home.packages` contains the package and that evaluation succeeds.
     - **`hm-override`**: `hm-plain` with
       `programs.omateams.package = pkgs.hello`. It asserts that `hello` is
       in `home.packages`.
     - **`hm-nixarchy-override`**: `hm-nixarchy` with the same override. It
       asserts that both `home.packages` and the plugin `src` use `hello`.
     - **`nixos-override`**: the `nixos` check with
       `programs.omateams.package = pkgs.hello`. It asserts that `hello` is in
       `environment.systemPackages`.
     - **`nixos`**: `nixpkgs.lib.nixosSystem` with a minimal config
       (`boot.isContainer = true`, `system.stateVersion`) and the module
       enabled. It asserts that `environment.systemPackages` contains the
       package. Each check forces only the attribute it asserts on, never
       `toplevel`.

     Each check is a `pkgs.runCommand` whose name holds the forced boolean,
     using `assert ...; pkgs.runCommand "..." { } "touch $out"`.

   Verify (lead):

   ```bash
   nix flake check --all-systems --no-build
   nix flake check
   nix flake show
   ```

   - The first evaluates both systems, so aarch64 is covered at evaluation.
   - The second builds and runs every check here.
   - The third lists every output.

3. **`nix/home.nix`: the home-manager module.**

   ```nix
   self: { config, lib, pkgs, options, ... }:
   let cfg = config.programs.omateams; in {
     options.programs.omateams = {
       enable = lib.mkEnableOption "omateams, Microsoft Teams for Omarchy";
       package = lib.mkOption {
         type = lib.types.package;
         default = self.packages.${pkgs.stdenv.hostPlatform.system}.omateams;
         defaultText = lib.literalExpression "omateams.packages.\${pkgs.stdenv.hostPlatform.system}.omateams";
         description = "The omateams package. On NixOS, override it with the system Hyprland: `.override { hyprland = osConfig.programs.hyprland.package; }`.";
       };
     };
     config = lib.mkIf cfg.enable (lib.mkMerge [
       { home.packages = [ cfg.package ]; }
       # nixarchy's plugin option is only there when nixarchy is imported;
       # the declared options are checked, never config, so this cannot recurse.
       (lib.optionalAttrs (lib.hasAttrByPath [ "programs" "nixarchy" "plugins" ] options) {
         programs.nixarchy.plugins.omateams.src = "${cfg.package}/share/omateams/plugin";
       })
     ]);
   }
   ```

   Verify (lead): the `hm-*` checks from step 2 pass.

4. **`nix/nixos.nix`: the NixOS module.**
   - `enable`.
   - `package`, which defaults to
     `self.packages.${system}.omateams.override { hyprland = config.programs.hyprland.package; }`.
   - `config = lib.mkIf cfg.enable { environment.systemPackages = [ cfg.package ]; }`.
   - One comment saying the plugin wiring is in the home-manager module.

   Verify (lead): the `nixos` check passes.

5. **`README.md`: a "Nix" section** after the install section.
   - The flake input, with `inputs.nixpkgs.follows`. Don't make `nixpkgs-qt`

   - Without nixarchy, point Omarchy at the packaged plugin by linking

   - The NixOS module.
   - `nix run github:olafkfreund/omateams`.
   - Settings stay in the shell UI.
   - Only `x86_64-linux` is built here; `aarch64-linux` is evaluated only.

   Verify: read it back against the spec.
